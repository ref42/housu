# Changelog

## 0.8.0

- Keep type and parameter hints transparent and readable inside selections.
- Give focused completion, command palette, explorer and menu rows a blue background.
- Keep the main editor palette to charcoal, warm gray, muted blue and amber;
  retain red/green only for functional status feedback.
- Add clearer green/red diff lines and inline borders while preserving syntax contrast.
- Return whitespace markers and indentation guides to VS Code defaults so they stay quiet.
- Narrow syntax scopes so attributes, macros and function calls retain their inner colors.
- Restore dark ANSI black and give all eight bright terminal colors distinct values.
- Add automated validation, VSIX build artifacts and release documentation.
